# Fair Catan Boards

Map generator for *The Settlers of Catan* that ensures perfectly balanced, fair, and competitive maps.

**[Test the Live Demo](https://mowwis.github.io/fair-catan-board-generator/)**


## Features

*   **Desert Isolation:** Never touches the ocean coastline.
*   **Resource Dispersion:** Max 2 identical resource types adjacent.
*   **No Adjacent Identical Numbers:** Prevents clustering of identical numbers.
*   **Red Token Separation:** High-yield numbers (6 & 8) never touch.
*   **Vertex Production Cap:** No intersection spot exceeds 11 total pips.
*   **Yield Equity:** Dynamically balances resource distribution (<10% variance).
*   **Alternating Ports:** Perfectly symmetric maritime trade harbor rotation.
*   **Heatmap Mode:** Instant visual aid to analyze production hot spots.
